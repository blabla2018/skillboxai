# Публикация без личных путей

`skillboxai-public.zip` — снимок файлов проекта для публикации без `.git`, локальных служебных каталогов и этого каталога `publication/`. Учебные материалы, инструкции и подготовленные карточки включены; несвязанные локальные аудиофайлы из `output/` не включены.

В текущем дереве проверены текст и имена файлов: личные пути и идентификаторы пользователя удалены. Вместо домашнего пути к предоставленному материалу оставлено исходное имя файла. Публичные ссылки школы сохранены.

В существующей локальной Git-истории остаются персональные данные: авторство трёх коммитов и прежняя версия одного файла с домашним путём. История не переписывалась, никакие коммиты или файлы на GitHub не отправлялись. Обычный push этой истории сохранит эти данные.

Для публикации без старой истории распакуйте архив в новый каталог и создайте новый репозиторий. Перед первым коммитом задайте желаемые публичные имя автора и email. Сам архив не содержит Git-авторства. Связь с аккаунтом GitHub зависит от выбранного аккаунта и настроек публикации.
