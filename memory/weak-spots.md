# Teacher Feedback Index

Teacher feedback is stored separately by target language:

- English: `teacher-feedback-english.md`
- Spanish: `teacher-feedback-spanish.md`

Do not add phrases to this compatibility index. In the language-specific files, `[x]` means the phrase or construction appears in a recorded card, while `[ ]` means it has not been used in a recorded card yet. This is source-usage metadata, not learning or mastery status.
