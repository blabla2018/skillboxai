# Project Memory

This folder stores durable working notes for language-card generation in this Codex project.

Use these files before creating new English or Spanish learning material:

- `workflow.md` - general workflow for lesson/card creation.
- `remnote-format.md` - output formatting rules for RemNote.
- `english-skillbox.md` - Skillbox-specific English workflow.
- `spanish-cards.md` - Spanish-card workflow, independent of Skillbox.
- `teacher-feedback-english.md` - dated English teacher feedback with explicit used/unused card status.
- `teacher-feedback-spanish.md` - Spanish teacher feedback with explicit used/unused card status; never mixed with English.
- `used-english-cards.md` - already used English cards to avoid duplicates.
- `used-spanish-cards.md` - already used Spanish cards to avoid duplicates; independent of the English history.
- `useful-phrases.md` - useful phrases collected from lessons and drills.
- `weak-spots.md` - compatibility index pointing to the two language-specific teacher-feedback registries; do not add phrases there.

Do not store passwords, tokens, private account details, or other sensitive data here.
