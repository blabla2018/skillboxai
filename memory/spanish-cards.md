# Spanish Cards Workflow

Use this workflow for Spanish learning material.

Do not use Skillbox. Work from the user's provided topic, text, examples, corrections, or vocabulary.

1. Identify the grammar or lexical focus.
2. Explain the rule briefly in Russian.
3. Use any user-provided problem words, corrections, or examples as priority material.
4. Embed cards directly into the theory when possible.
5. Make cards useful for real speech, not just mechanical drills.
6. Avoid duplicates and near-duplicates from existing notes if the user provides them.

Card format:

```text
русское предложение==Spanish translation
```
