# Spanish Cards Workflow

Use this workflow for Spanish learning material.

Do not use Skillbox. Work from the user's provided topic, text, examples, corrections, or vocabulary.

Apply the general workflow and RemNote format exactly as for English cards. Spanish and English are independent card lists: never compare Spanish cards against English history, and never mix their entries.

1. Identify the grammar or lexical focus.
2. Before candidate selection, append every newly observed Spanish teacher-recommended phrase from the user's source, teacher note, or website to `teacher-feedback-spanish.md` with its source/date and unchecked status. Do not copy English feedback into this file.
3. Use user-provided problem words, corrections, examples, and Spanish teacher feedback as priority material when they fit naturally.
4. Make cards useful for real speech, not just mechanical drills.
5. Before composition, check `used-spanish-cards.md` for exact duplicates, the same key phrase, and near-duplicate meanings.
6. Add a brief Russian formula or explanation only when it materially helps interpret the cards; otherwise return cards only.
7. After an approved or reusable batch, add it to `used-spanish-cards.md` when the user wants project memory to stay current.
8. After recording the batch, mark only the Spanish teacher-feedback phrases actually present in those cards as checked in `teacher-feedback-spanish.md`, with `used in` evidence naming the card-set heading. Leave all other entries unchecked.

Card format:

```text
русское предложение==Spanish translation
```
